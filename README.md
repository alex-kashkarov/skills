# Skills

Open-source agent skills and playbooks.

This repository stores reusable skill packages for AI agents. Skills may target Codex, Claude, Cursor, or other agent environments, depending on the package.

## Available Skills

- `Skills/landing-page-architect` - create, audit, or rewrite product and service landing pages using offer diagnosis, conversion structure, proof, risk reduction, and CTA guidance.
